# claude-mods

My Claude Code mods — one directory per mod, installable as a marketplace.

## Install a mod

```bash
claude plugin marketplace add Yuuichu/claude-mods
claude plugin install usage-statusline@yuuchu-claude-mods
```

## Mods

| Mod | What it does |
| --- | --- |
| [usage-statusline](./usage-statusline) | One-line usage status above the prompt: model, context %, rate-limit windows, cost, live tok/s, session deep-link button |
